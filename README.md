# IBJJF Rules Book — Interactive (unofficial prototype)

An **unofficial prototype** of an interactive version of the IBJJF rules book, with embedded videos. It is a test site and is **not affiliated with or endorsed by the IBJJF or CBJJ**. Always consult the official rulebook.

- English: `en/`
- Português: `pt/`

Each language is a self-contained single HTML file. Served via GitHub Pages from `main` (root).
